# BetterTot 0.2.0

BetterTot 0.2.0 refines the scratchpad and introduces a redesigned settings
experience while preserving the local-first storage model from 0.1.0.

## Highlights

- Redesigned settings with compact vertical navigation for General, Editor,
  Storage, and Updates.
- Clearer setting rows, backup metrics, update status, and application version
  presentation.
- Native glass treatment for the settings sidebar on macOS 26, with a stable
  material fallback on earlier supported macOS versions.
- Restored the scratchpad's flat surface and borderless colored pad dots for
  consistent contrast over both light and dark backgrounds.
- Removed the panel shadow that could produce a visual pointer artifact while
  retaining the rounded window silhouette.
- Stabilized selected settings rows so icons render once without animation or
  redraw artifacts.

## Requirements

- macOS 13 Ventura or later.
- Apple silicon or Intel Mac. The application is distributed as a universal
  `arm64` and `x86_64` binary.

## Installation

Download `BetterTot-0.2.0.pkg` for the standard Installer flow, or extract
`BetterTot-0.2.0.zip` and move `BetterTot.app` to `/Applications`. Verify both
files against `BetterTot-0.2.0.sha256` before installation.

The app is ad-hoc signed, the installer is unsigned, and neither artifact is
notarized. macOS may require explicit approval through Privacy & Security;
never disable Gatekeeper globally.

## Upgrade Safety

Quit BetterTot before upgrading. Existing pads, journals, backups, editor
preferences, and shortcut settings remain in their current locations and are
not part of the application bundle.

## Verification

The release candidate passes all 134 automated tests and the enforced coverage
gate, with 87.94% line coverage.

## Known Limitations

- Pad names and colors are persisted internally but are not editable.
- Backups and recovered journal versions remain until manually removed.
- Sync and automatic crash reporting are not included.
- Command-Left Arrow and Command-Right Arrow switch pads rather than moving the
  text cursor to the beginning or end of a line.
