# BetterTot 0.3.0

BetterTot 0.3.0 expands the scratchpad editor, moves backups to one predictable
iCloud Drive location, and makes local development updates safer.

## Highlights

- Eight color-coded scratchpads with editable names and colors.
- Live Markdown styling for headings, emphasis, inline code, links, and task
  lists while preserving portable Markdown source text.
- Larger native checkboxes, pad-colored emphasis, automatic list continuation,
  and footer controls for bullets, numbered lists, and checklists.
- iCloud-only rolling backups in the deterministic `BetterTot Backups
  (org.bettertot.BetterTot)` folder, with latest-backup time and size in
  Settings.
- Daily automatic update checks for bundled builds, plus the existing manual
  check action. BetterTot never downloads or installs updates automatically.
- Compact settings navigation, native controls, and dedicated Pads, Editor,
  Storage, and Updates pages.
- `Control-Tab` and `Control-Shift-Tab` switch pads without overriding standard
  Command-Arrow text navigation.
- Autocorrect and text-input suggestion clicks no longer dismiss the scratchpad.
- A local build-and-install command safely replaces and relaunches the copy in
  `/Applications` while keeping release artifact generation separate.

## Requirements

- macOS 13 Ventura or later.
- Apple silicon or Intel Mac. Release artifacts are universal `arm64` and
  `x86_64` binaries.
- iCloud Drive for rolling backups. Editing and crash recovery remain available
  when iCloud Drive is offline or unavailable.

## Installation

Download `BetterTot-0.3.0.pkg` for the standard Installer flow, or extract
`BetterTot-0.3.0.zip` and move `BetterTot.app` to `/Applications`. Verify both
files against `BetterTot-0.3.0.sha256` before installation.

The app is ad-hoc signed, the installer is unsigned, and neither artifact is
notarized. After verifying the SHA-256 checksum, open the package normally. If
macOS blocks it, use **System Settings → Privacy & Security → Security → Open
Anyway**, authenticate, and confirm **Open**. Only create this exception for a
checksum-verified download from this repository; never disable Gatekeeper
globally.

## Upgrade Safety

Quit BetterTot before upgrading. Pad files, journals, workspace metadata,
editor preferences, and iCloud backups live outside the application bundle and
remain available after replacing or reinstalling BetterTot.

BetterTot migrates recognized backups from the former local or user-selected
mirror layout after iCloud Drive becomes available. Migration copies verified
snapshots and does not delete legacy source folders.

## Known Limitations

- The current ad-hoc-signed build uses the visible iCloud Drive folder rather
  than an entitlement-backed app container.
- Backup requires iCloud Drive; there is no selectable local backup destination.
- Automatic update checks report availability only. Updating remains manual.
- Sync between open BetterTot instances and automatic crash reporting are not
  included.
