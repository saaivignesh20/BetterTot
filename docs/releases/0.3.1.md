# BetterTot 0.3.1

BetterTot 0.3.1 fixes autocorrect and spelling-suggestion interactions while
the scratchpad is unpinned.

## Fixes

- Clicking a macOS autocorrect or spelling suggestion displayed over the
  editor no longer dismisses an unpinned scratchpad.
- Text-input helper windows remain interactive without weakening normal
  outside-click dismissal.

## Requirements

- macOS 13 Ventura or later.
- Apple silicon or Intel Mac. Release artifacts are universal `arm64` and
  `x86_64` binaries.

## Installation

Download `BetterTot-0.3.1.pkg` for the standard Installer flow, or extract
`BetterTot-0.3.1.zip` and move `BetterTot.app` to `/Applications`. Verify both
files against `BetterTot-0.3.1.sha256` before installation.

The app is ad-hoc signed, the installer is unsigned, and neither artifact is
notarized. After verifying the SHA-256 checksum, open the package normally. If
macOS blocks it, use **System Settings -> Privacy & Security -> Security -> Open
Anyway**, authenticate, and confirm **Open**. Never disable Gatekeeper globally.

## Upgrade Safety

Quit BetterTot before upgrading. Pads, workspace metadata, preferences, and
iCloud backups live outside the application bundle and remain available after
replacing or reinstalling BetterTot.
