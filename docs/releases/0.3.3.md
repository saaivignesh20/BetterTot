# BetterTot 0.3.3

BetterTot 0.3.3 refines the scratchpad and Settings experience while keeping
the existing workspace and backup formats unchanged.

## Improvements

- The scratchpad uses a native blurred popover surface in light and dark
  appearances.
- Footer statistics use the compact `chars` label and can be hidden from
  **Settings -> General -> Text Statistics**.
- Settings command buttons use native Liquid Glass on macOS 26 or later and
  retain standard rounded controls on earlier supported releases.
- The iCloud backup summary is more compact, with backup actions grouped in
  one place.
- Pad name fields retain their standard editable background and border.
- Pad name field styling remains consistent on macOS 13 through macOS 27.
- Inline checkboxes align more consistently with editor text.
- The README, website, and product demonstration have been refreshed to match
  the current application.

## Requirements

- macOS 13 Ventura or later.
- Apple silicon or Intel Mac. Release artifacts are universal `arm64` and
  `x86_64` binaries.

## Installation

Download `BetterTot-0.3.3.pkg` for the standard Installer flow, or extract
`BetterTot-0.3.3.zip` and move `BetterTot.app` to `/Applications`. Verify both
files against `BetterTot-0.3.3.sha256` before installation.

The app is ad-hoc signed, the installer is unsigned, and neither artifact is
notarized. After verifying the SHA-256 checksum, open the package normally. If
macOS blocks it, use **System Settings -> Privacy & Security -> Security -> Open
Anyway**, authenticate, and confirm **Open**. Never disable Gatekeeper globally.

## Upgrade Safety

Quit BetterTot before upgrading. Pads, workspace metadata, preferences, and
iCloud backups live outside the application bundle and remain available after
replacing or reinstalling BetterTot.
