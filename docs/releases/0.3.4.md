# BetterTot 0.3.4

BetterTot 0.3.4 tightens the scratchpad controls and keeps the website aligned
with the native app. Workspace and backup formats are unchanged.

## Improvements

- The scratchpad header is more compact, with smaller controls and pad dots.
- The panel uses AppKit's native popover material for dark blurred transparency.
- The menu-bar icon shows an active state while the scratchpad is open.
- Footer statistics stay on the left while list and Settings controls stay on
  the right.
- The website now renders its product demos in HTML and CSS, with corrected
  menu-bar alignment and direct local asset loading.

## Requirements

- macOS 13 Ventura or later.
- Apple silicon or Intel Mac. Release artifacts are universal `arm64` and
  `x86_64` binaries.

## Installation

Download `BetterTot-0.3.4.pkg` for the standard Installer flow, or extract
`BetterTot-0.3.4.zip` and move `BetterTot.app` to `/Applications`. Verify both
files against `BetterTot-0.3.4.sha256` before installation.

The app is ad-hoc signed, the installer is unsigned, and neither artifact is
notarized. After verifying the SHA-256 checksum, open the package normally. If
macOS blocks it, use **System Settings -> Privacy & Security -> Security -> Open
Anyway**, authenticate, and confirm **Open**. Never disable Gatekeeper globally.

## Upgrade Safety

Quit BetterTot before upgrading. Pads, workspace metadata, preferences, and
iCloud backups live outside the application bundle and remain available after
replacing or reinstalling BetterTot.
