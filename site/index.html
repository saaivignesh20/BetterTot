BetterTot

A scratchpad in your menu bar.

Open it, write something down, close it.

Download for macOS

Version 0.3.1 · macOS 13 or later

Seven pads, no folders.

Give each one a name and color. Switch with Command-1 through Command-7.

Markdown stays text.

Headings, links, lists, and checkboxes remain readable outside BetterTot.

Saved on your Mac.

Notes save locally with crash recovery. iCloud Drive keeps rolling backups. No BetterTot account or telemetry.

The current release is ad hoc signed and not notarized. Verify the published SHA-256 checksum, then use System Settings > Privacy & Security > Open Anyway if macOS blocks it. Never disable Gatekeeper.
