01 / Instant capture

A note without a detour.

Press Option-Command-Space from any app. BetterTot opens from the menu bar, saves as you type, and closes when you are done.

02 / Seven pads

A pad for each thread.

Each colored dot opens a separate pad. Switch with Command-1 through Command-7 and keep work, errands, and temporary text apart.

03 / Markdown and checklists

Plain text, with useful structure.

Type Markdown for headings, emphasis, code, links, lists, and tasks. BetterTot styles it in place while the files remain ordinary UTF-8 text.

04 / Storage

Saved on your Mac. Copied to iCloud.

Your editable pad files live in Application Support. BetterTot also keeps rolling snapshots in its own iCloud Drive folder. No BetterTot account or analytics.

Unsigned release

Install BetterTot in three steps.

The app is ad-hoc signed, and its installer is unsigned and not notarized, so macOS may ask you to approve it once.

Download latest release
  1. 1
    Download both files

    Get the `.pkg` installer and `.sha256` checksum from the latest release.

  2. 2
    Check the package

    Run shasum -a 256 BetterTot-*.pkg and match the result with the checksum file.

  3. 3
    Open the installer

    If macOS blocks it, use System Settings > Privacy & Security > Open Anyway. Keep Gatekeeper enabled.
