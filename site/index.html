BetterTot

Eight scratchpads. One shortcut. No workflow.

A native, local-first scratchpad that stays in your macOS menu bar until you need it.

Download for macOS View source

macOS 13+ · Apache 2.0 · No BetterTot account

Built for quick capture

A scratchpad, not a filing system.

Always one shortcut away

Open BetterTot globally, switch between eight pads, then dismiss it without leaving your current app.

Markdown without the clutter

Headings, emphasis, links, code, lists, and checkboxes style live while the portable source stays intact.

Local-first by design

Plain-text pads, atomic saves, crash recovery, and no analytics. Editing never depends on a network.

Backed up to iCloud Drive

Rolling backups use one predictable app-owned folder and survive ordinary updates and reinstalls.

Native macOS behavior

Small enough to stay out of the way.

  • Pin by dragging. Keep a pad visible when you need a temporary working surface.
  • Use real controls. Native checkboxes, spelling, undo, and optional Apple Writing Tools.
  • Keep your shortcuts. Standard Command-Arrow text navigation remains untouched.
  • Own your text. Import, export, or read every pad without BetterTot.

Install BetterTot 0.3.0

Download, verify, install.

Choose the installer package or ZIP from GitHub Releases. Compare its SHA-256 value with the published checksum before opening it.

Open latest release
  1. Open the checksum-verified .pkg and attempt installation normally.
  2. If macOS blocks it, open System Settings → Privacy & Security.
  3. Under Security, choose Open Anyway, authenticate, and confirm.

Unsigned release: the app is ad-hoc signed, the package is unsigned, and neither is notarized. Never disable Gatekeeper globally.
